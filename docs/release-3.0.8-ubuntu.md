# Music Time 3.0.8 — Ubuntu

Pacote final para Ubuntu Desktop 24.04 amd64 com [os ajustes da versão 3.0.8](https://github.com/eugilvando/Music-Time-Player/blob/main/docs/release-3.0.8.md): ações da fila em uma linha e seletor Capa / Apenas letras também fora da tela cheia.

```bash
sudo apt install ./music-time-preview_3.0.8-0ubuntu1_amd64.deb
```

Feche o app antes de atualizar. O identificador `music-time-preview` é mantido para compatibilidade com instalações anteriores. A validação automatizada inclui testes, build, instalação, abertura gráfica e MPRIS; uso em VM/partição com dispositivos reais permanece sujeito à avaliação do usuário.
