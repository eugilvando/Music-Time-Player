# Music Time 2.9.0 — Ubuntu 24.04 x64

Choose Current (Material Symbols Rounded), Solar or Phosphor under Settings → General and appearance → Icons. Select Filled or Outlined and compare the live preview. The preference applies immediately, including menus and dialogs, and persists on this device. Existing installations retain the current filled appearance by default.

All 104 application action symbols have bundled equivalents in both added families and styles. Solar uses Bold/Linear; Phosphor uses Fill/Regular. Assets are bundled for offline use. Provider logos and Music Time branding retain their identity. Favorites still indicate state through the existing color and outline behavior. General settings reset restores the original icon defaults.

Solar artwork is CC BY 4.0 by 480 Design; Phosphor is MIT. Attribution is available in About, Third-party licenses and the bundled notices.

Windows and Ubuntu 24.04 x64 distributions are delivered separately. Ubuntu real audio, tray and cloud-account acceptance remains separate from automated validation. See each release validation manifest for the tests and installer checks actually completed.

Install or upgrade after closing Music Time:

```sh
sudo apt update
sudo apt install ./music-time-preview_2.9.0-0ubuntu1_amd64.deb
```
