# Music Time 3.0.7 — Ubuntu

Pacote final para Ubuntu Desktop 24.04 amd64. Inclui o mesmo conjunto de funcionalidades da [versão 3.0.7](release-3.0.7.md).

```bash
sudo apt install ./music-time-preview_3.0.7-0ubuntu1_amd64.deb
```

Feche o aplicativo antes de atualizar. O nome do pacote continua `music-time-preview` para manter atualizações compatíveis. A interface Sobre identifica o pacote instalado e permite consultar releases compatíveis.

A validação automatizada cobre análise, testes, build Linux, instalação Debian, abertura gráfica e sessão MPRIS. Consulte `release/validation-ubuntu.json` para os resultados finais. Validação de áudio, bandeja e troca de saída em uma partição ou VM com os dispositivos reais continua pendente da avaliação do usuário.
