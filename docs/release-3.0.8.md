# Music Time 3.0.8

- A fila reúne ir para a faixa atual, repetir, shuffle, salvar playlist, contagem e opções em uma única linha.
- Salvar playlist passa a ser um botão apenas com ícone, com descrição ao passar o mouse e para leitores de tela.
- A tela de reprodução normal também oferece Capa / Apenas letras ao lado do botão de tela cheia.
- A escolha é compartilhada entre os dois modos e não altera a música, a fila ou a posição de reprodução.
- Selecionar um estilo nas configurações ou restaurar as preferências de reprodução continua funcionando normalmente.

Windows: `MusicTime-Setup-3.0.8.exe`. Dados e preferências são preservados na atualização.

Consulte os manifestos em `release/` para validações e hashes dos instaladores. A validação Windows usa o computador local; o ambiente remoto sem saída de áudio física não substitui os testes de reprodução. Ubuntu é validado automaticamente; a aceitação em VM/partição com dispositivos reais permanece separada.
