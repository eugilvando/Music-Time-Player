# Music Time 2.0.0+44

24 October 2026 · Windows x64

- Figma-based redesign with local Inter, Bricolage Grotesque and rounded symbols; refined sidebar, topbar, buttons, dialogs, player and queue/lyrics selector.
- All existing Home sections and five Now Playing styles retained, including Vinyl.
- Nine settings categories aligned with the final design, with per-section cards, reorganized settings and preserved preferences.
- Figma card/compact-card sizes and selectable detailed-list columns, including playlists; configurable player-bar spacing and continuous-play quantity.
- Selective compressed backups, optional artwork, playlist-only import, provider IDs and optional password-encrypted sessions/credentials. Legacy JSON import remains available.
- Remote MP3 duration from Xing/Info/VBRI frame counts; optional failures preserve known metadata, and unknown duration is not estimated from file size.
- Includes OneDrive identity/source-removal fixes and the Google Drive visual folder picker from 1.2.2.

Validation results and artifact hashes are recorded in [the release manifest](../release/validation.json). Screenshots show an isolated fictional library rendered by the actual application. They do not demonstrate real-account acceptance.

Each user supplies their own Google/Microsoft OAuth registration. See [provider setup](provider-setup.md), [backup instructions](backup.md) and [privacy](privacy-and-data.md). No personal database, credentials, backups or SDK are included.
