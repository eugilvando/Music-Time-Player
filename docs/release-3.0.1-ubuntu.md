# Music Time 3.0.1 — Biblioteca personalizável

A Biblioteca agora tem um seletor **Tamanho dos cards**, com cinco opções: Extra pequeno, Pequeno, Médio, Grande e Extra grande. A escolha é aplicada imediatamente, fica salva e é independente dos cards de outras páginas.

Os atalhos recebem cores próprias, fundos em degradê e ícones destacados. O resumo da coleção também ganha cor. O layout se adapta à largura disponível, ao tema claro/escuro e ao tamanho do texto.

Mantém os recursos da versão 3.0: central da Biblioteca, Músicas com rolagem contínua, linhas alternadas, contornos reforçados, cache de navegação e controles MPRIS no Linux.

Consulte os manifestos de Windows e Ubuntu para as validações concluídas. Todas as capturas usam dados fictícios.

Atualização Ubuntu: `sudo apt install ./music-time-preview_3.0.1-0ubuntu1_amd64.deb`. O identificador existente é preservado para atualizar o perfil.
